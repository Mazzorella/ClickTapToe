# ClickTapToe Docs

- [Hub assembly photo guide](https://mazzorella.github.io/ClickTapToe/docs/hub-assembly.html) covers the enclosure, scroll sensor, hub board, and slipper connection.
- [Electronics parts list](assets/clicktaptoe-electronics-bom.csv) covers components in the two board assembly orders.
- [Flashing and hardware tests](../README.md#flashing) cover loading the firmware and checking the controls.
- [Next steps](NEXT_STEPS.md) tracks deferred firmware and board work.

Guide photos are in `assets/assembly/`. Filenames start with the matching
two-digit step number and use a letter when the step shows multiple views,
such as `05a-scroll-wheel-insert.jpg`. The guide groups each step's photos in
a gallery and lists fastener sizes in the instructions. Keep the full-resolution
source photos in the ignored `assets/assembly/originals/` folder.
