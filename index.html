Assembly Guide

This is the high-level build order for the current electronics. Use the board previews and BOMs above for part placement and orientation.

Order the boards

Use each production archive for the matching PCB. Keep the input hub and mouse pointer fabrication packages separate.

Assemble surface-mount parts

Populate the controller-side passives, ESD arrays, sensor support parts, and board-specific footprints from each BOM.

Install connectors

Fit the USB/controller module, RJ45 jacks, pedal jacks, battery or auxiliary connectors, and any test headers used for bring-up.

Mount sensors

Place the AS5600 near the scroll wheel magnet and mount the PMW3610 sensor board in the pointer module at the intended height.

Wire the pointer link

Connect the input hub and pointer module with the RJ45 cable, preserving the non-Ethernet ClickTapToe pinout.

Flash and test

Flash the XIAO BLE with the ClickTapToe ZMK build, then verify pedal clicks, scroll movement, and PMW3610 pointer response.

RJ45 Pointer Pinout

The RJ45 connector is used as a ClickTapToe sensor cable, not as an Ethernet connection.

RJ45 pin Signal Input hub side Mouse pointer side
1 VIN / 3V3 3.3 V sensor power Sensor board input power
2 GND Ground Ground return
3 SCLK PMW3610 SPI clock PMW3610 SPI clock
4 SDIO Bidirectional SPI data Bidirectional SPI data
5 nCS PMW3610 chip select PMW3610 chip select
6 GND Ground Ground return paired with SCLK
7 MOTION PMW3610 motion interrupt Active-low PMW3610 motion output
8 nRESET Reset routed to XIAO D6 Reset routed through installed link

Next hardware improvement

For the next input hub PCB revision, add optional 0 ohm jumpers from each pedal jack normal contact to GND. Populate them for normally closed Yamaha-style pedals so unplugged jacks stay idle.

Firmware target

The active firmware target is xiao_ble//zmk with the clicktaptoe shield. The current build uses USB HID mouse output with Bluetooth disabled.
