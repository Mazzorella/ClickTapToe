This derivative version modifies the original PMW3610 breakout for the
ClickTapToe project by adding an RJ45 connector and related wiring changes.

The imported baseline commit only renames and relocates the cleaned PMW3610
source into the ClickTapToe hardware tree. RJ45-specific design changes are
tracked in later commits.
