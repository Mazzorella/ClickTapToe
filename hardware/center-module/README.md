# Center Module Hardware

This folder is reserved for the ClickTapToe center module PCB.

The center module provides the TS pedal jack connections and the RJ45 connection to the right-foot pointing module. Future KiCad source files, fabrication outputs, and board-specific notes should live here.

## Planned Layout

- `kicad/` for KiCad project source files
- `production/` for generated Gerbers, drill files, BOMs, and placement files
