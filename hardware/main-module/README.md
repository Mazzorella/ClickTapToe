# Main Module Hardware

This folder is reserved for the ClickTapToe main module PCB.

The main module houses the XIAO nRF52840 controller and the large foot-operated scroll wheel mechanism. Future KiCad source files, fabrication outputs, and board-specific notes should live here.

## Planned Layout

- `kicad/` for KiCad project source files
- `production/` for generated Gerbers, drill files, BOMs, and placement files
